## What it does

`main.ts` writes exactly two lines to `/output/entry.txt`:

- Line one warns my past self about one specific moment — a 2 a.m. text
  that starts "I miss us" — in a single sentence.
- Line two says in one sentence why that moment mattered: she leaves it on
  read, and the year after is spent checking a phone that already told the
  truth.

The text is 1–280 characters, plain and vivid, with one concrete moment
(a time, a named person, a sentence said out loud) and a clear cause and
effect in the second line.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

No dependencies, no network, deterministic output.
